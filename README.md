# PID Lab · 控制实验台

面向热控与自动化工程师的交互式 PID 教学演示。通过调整控制器与对象参数，观察闭环响应、抗扰能力、输出限幅和积分饱和的影响。

## 在线使用

- [工程控制实验台](https://liuliuliu-a11y.github.io/pid-control-lab/lab/)
- [原始水箱演示](https://liuliuliu-a11y.github.io/pid-control-lab/)

手机和电脑均可使用，无需安装。所有仿真在浏览器内运行。

## 主要功能

- 三类对象：一阶惯性＋迟延、二阶惯性＋迟延、积分型液位。
- Kp、Ti、Td 参数；积分和微分可独立启停。
- 设定值阶跃、持续负荷扰动、组合试验。
- 测量噪声、微分滤波、输出上下限、条件积分抗饱和。
- 设定值、真实值、测量值、控制输出及 P/I/D 贡献曲线。
- 保存一组参数和曲线，查看性能对比。
- 超调、最大偏离、调节时间、窗口末偏差、IAE、ITAE及输出限幅时间。
- 分享参数链接，导出包含配置与完整响应的 CSV。

## 第一次体验

1. 选择“仅比例”，观察窗口末偏差。
2. 点击“保存当前对比”。
3. 选择“PI 消偏”，观察积分如何改变偏差及动态过程。
4. 尝试“过强积分”“微分修正”“测量噪声”“抗扰响应”。

Ti 越小，积分作用越强；所有时间单位统一为分钟。调节时间仅在末段持续满足允许误差带至少 3 分钟时确认。窗口末偏差不自动等于稳态偏差。

## 模型边界

本项目采用通用教学模型，用于机理理解和参数效果比较。参数不代表具体现场设备的整定建议。液位越过 0–100% 时停止计算；不同对象或试验条件下的指标不直接用于优劣比较。

## 维护与发布

`public/` 是网页源目录；工程版位于 `public/lab/`，原始水箱文件位于 `public/index.html`。

主分支的网页源文件更新后，GitHub Actions 自动将 `public/` 发布到 GitHub Pages。也可以在 Actions 中手动运行 **Publish PID Lab**。

本地预览：

```sh
python -m http.server 8000 --directory public
```

打开 `http://localhost:8000/lab/`。无需安装前端依赖或运行构建。

`dist/` 与 `.openai/hosting.json` 保留原 Sites 发布配置；GitHub Pages 直接使用 `public/`，修改后无需同步 `dist/` 即可更新 GitHub Pages。

原始水箱导出文件保持原样，保留其沙盒化 iframe 和 CSP。
